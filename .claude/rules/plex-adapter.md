# The Plex adapter (`crates/api-plex`)

A binding: parse the request, run a GraphQL query in process (`gql::execute`, as the caller via
`gql::run_as_caller`), shape the `MediaContainer`. It depends on `api` and `transcoder`, never on
`db` or the ports. A condition expressing a domain rule in a handler is in the wrong place —
put it in `core`; listing order and wire encodings *are* the binding's.

Numbers Plex publishes are decoded from / encoded into global ids with `klapz_api::GlobalId`.

## Workflow for an endpoint

1. Capture the reference first (`reference-servers` skill); `docs/plex/wire-format.md` gives each
   field's JSON type, `docs/plex/spec-gaps.md` what the spec gets wrong. Suspect a wrong path
   parameter before concluding a route is absent.
2. Expose what is missing on the official API (see the GraphQL rule).
3. Write the handler; when a stub becomes real run `python tools/gen_stub_routes.py` then
   `cargo fmt` — a stub left beside the real route crashes startup on the duplicate.
4. `python tools/gen_endpoints.py` and diff `docs/plex/ENDPOINTS.md`: an unparsable row silently
   falls back to `todo`. Off-spec routes go in `OFF_SPEC`.
5. Tests from real captured fixtures (`tests/fixtures`), never invented data; record any new
   behavior or divergence in `docs/plex/spec-gaps.md`.

## Wire rules settled by capture

- JSON iff `Accept` contains `application/json`, else XML (`*/*` is XML); no `?format=`. XML is
  exactly `text/xml;charset=utf-8`.
- Errors are minimal `text/html`, whatever was negotiated; clients branch on the status.
- Types are per field: `ratingKey` a string, `Media.id` a number; booleans `0`/`1` in XML but
  per field in JSON (`allowSync: true`, `hasPremiumPrimaryExtra: "1"`, `hidden: 0`).
- Attribute order is not alphabetical (`serde_json` with `preserve_order`).
- The XML element of a listing item follows its `type` (`<Video>`, `<Directory>`), the one
  place XML and JSON are not isomorphic.
- Paging only when `X-Plex-Container-Start` **and** `-Size` are both given; responses send
  `X-Plex-Container-Start` and `-Total-Size` only. Listings always window here
  (`page::MAX_ITEMS`) and say so (`totalSize`, `offset`).
- Every response: `X-Plex-Protocol: 1.0`, `Cache-Control: no-cache`.
- `X-Plex-*` from header or query (`ClientIdentity`): a header wins even empty, header names
  case-insensitive, query names not, last repeated query value wins, nothing trimmed, never
  rejects.
- A filter on the advertised list (`Meta/Type/Filter`) we cannot translate answers `501`;
  parameters not on that list are tolerated. `Meta` lists only what we honor; a test keeps it in
  step with `listing::parse`.
- Range operators need their `>` encoded (`year%3E=2020`); `hyper` rejects a raw `>`.

## Deliberate answers (details in `docs/plex/spec-gaps.md`)

- Announces Plex `1.43.5.11029-6bf8af3f0` (Plex Web refuses older), all 209 `ownerFeatures`,
  `myPlexSubscription` true: no paywall, ever.
- `/:/prefs` is `403` (server settings live in `Server.settings`); `allowChannelAccess=0`.
- Every path-taking route is refused `403` (`/playlists/upload`, `refresh?path=`, extras by
  URL). `/photo/:/transcode`, `/services/ultrablur/*` fetch over TLS from `plex.tv` hosts only.
- Each token sees its own user's server: its own machine identifier, history (`accountID` 1),
  playlists. `/hubs/popularInLibraries` is `404`; `/users/top` lists the caller only.
- Live TV, DVR and music answer as a server with nothing set up (`livetv.rs`, `music.rs`).
- Online subtitle search finds nothing; both `nearest` routes `403`; a transcoder fallback is
  always refused (`412`).
- `/library/metadata/{id}/userState` exists here (plex.tv's Discover shape, always unwatched).
- Extras, provider trailers included, are listed to everyone; the first trailer is
  `primaryExtraKey` on films and series. A category tile shows `category-art/animation.png`.
- Ratings are 0–10 (`400` otherwise); a play queue made without `X-Plex-Client-Identifier`
  replaces nothing.
- `/tree` times are unshifted; `/library/tags` lists only what readable libraries carry.
- Language names come from CLDR 39 (`language_names.rs`, generated by
  `tools/gen_language_names.py`, `#[rustfmt::skip]`).
