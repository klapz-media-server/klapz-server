# Languages (`core::language`)

Every language field is one type. No crate keeps a language table of its own, but Plex's
labels (below).

- `Language`: one of the 598 languages CLDR 39 names, under its shortest ISO 639 code, `und`,
  `mul`, `zxx` and `mis` included. Every spelling a file or a provider uses reads as one:
  `fre`, `fra`, `fr`, `FRE`, `French` are `fr`.
- `LanguageTag`: a language with the script and region BCP 47 adds. A region keeps two dubs
  apart (TRUEFRENCH `fr-FR`, VFQ `fr-CA`); a language without one stands for all its regions
  in a filter, a region for itself alone. A well-formed code outside the list (`qaa`) is kept,
  its language `MIS`; a word naming no language (`unknown`) is none.
- Storage keeps the canonical tag only (migration `m0052`); the scan and the importer write
  nothing else. What a file wrote stays beside it as stated (`declared_language`).
- Official API: the `Language` enum, or `Locale` (`language`, `script`, `region`, `tag`,
  `name`, `nativeName`) and `LocaleInput` where a region counts. Only stated values stay text
  (`StatedTrack.language`, `SideStream.statedLanguage`, `TrackField.STATED_*_LANGUAGE`).
- Wire forms are derived from it in each adapter: Jellyfin's three-letter codes and English
  names, TVDB's codes, the transcoder's ISO 639-2 labels. Plex's labels are the exception:
  `api-plex::language_names` reproduces ICU 69's display of a tag in 32 locales, which is
  presentation.
- Both tables are generated by `python tools/gen_languages.py`:
  `crates/core/src/language/table.rs` and the enum's values, `crates/api/src/language/values.rs`.
